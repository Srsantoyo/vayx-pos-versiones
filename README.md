# VAYX-POS · versiones

Este repositorio es **público** y solo guarda los **instaladores** de VAYX-POS y la nota de cada
versión. **No tiene código**: el código de la caja está en un repositorio privado aparte.

## Para qué sirve

Las cajas de VAYX-POS revisan aquí, una vez al día y por internet, si hay una versión nueva
(fase C3, actualización automática con respaldo previo). Si la hay, la bajan, avisan al cajero y,
antes de instalarla, hacen un respaldo.

## Qué hay aquí

- Una publicación («Release») por cada versión aprobada por el dueño, con su instalador y lo que
  trae.
- El archivo que las cajas leen para saber cuál es la última versión.

Cada instalador viene firmado con una clave de VAYX: una caja no instala nada que no traiga esa
firma, aunque alguien suba un archivo aquí.

## Reglas

- Solo se publica una versión cuando el dueño la aprueba, después de su prueba de Windows en verde.
- Aquí no se suben claves, contraseñas, datos de clientes ni código.
